LAZYSTICK TOOLS

华为台灯授权

登录、选择台灯，下载用于 LazyStick 的授权文件。

01

连接本机助手

首次使用，请在 Windows 电脑下载并运行助手。

未连接
  1. 下载并解压，双击 LazyStick-Huawei-Auth.exe。
  2. 助手会自动打开此页面，连接后即可登录。
下载 Windows 助手

Windows 10 / 11，64 位；无需安装 Python。手机浏览器无法连接电脑上的助手。

02

登录华为账号

使用已绑定台灯的账号，仅支持中国大陆服务。

账号已登录

03

选择台灯并下载

仅显示支持的欧普智能台灯 2S。

未找到支持的台灯，请确认已在当前账号的华为智慧生活 App 中绑定。

下载后，在 LazyStick 设置页的“华为台灯”中导入并启用。

这是 LazyStick 的独立授权工具。账号、密码和验证码由本机助手直接发送给华为，站点不接收、不保存。授权仅在内存中保留，闲置 15 分钟后清除；下载的 JSON 含授权凭据，请妥善保管。
