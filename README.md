# LazyStick 巴法云远程控制页

在线地址：<https://lazystick.icu/>

设备固件镜像位于 `https://lazystick.icu/firmware/`。加密固件同时归档在本仓库的不可变
GitHub Release 中，由 `LazyStick_v2/scripts/publish-firmware.ps1` 核验加密包头、大小和
SHA-256 后同步；不要手工替换同名固件。

当前提供以下加密 OTA 固件，在设备的固件升级页粘贴下载地址即可：

- [0.4.0 标准版](https://lazystick.icu/firmware/LazyStick-0.4.0.ota.bin)：电脑、媒体、宏、定时和华为台灯控制，不包含树新风控制。
- [0.4.1 树新风版](https://lazystick.icu/firmware/LazyStick-0.4.1.ota.bin)：包含标准版全部功能，并提供 Treeow K2 设备发现和六个控制动作，需在设备配置页启用。

两个版本的联网与配网热点 Wi-Fi 最大发射功率均为 5 dBm。0.4 系列新增华为台灯授权导入和五个动作，并优化连接复用：实测普通控制约 1.2～1.5 秒，首次连接约 4 秒。0.3.0/0.3.1 保留为历史版本。版本元数据和 SHA-256 见 [固件清单](firmware/releases.json)。树新风可通过设备局域网控制页或米家模式 5 配对风速控制。

直接双击 `index.html`，使用现代版 Chrome、Edge、Firefox 或 Safari 打开即可。不需要安装软件或启动本地服务器，也不要求与 LazyStick 位于同一局域网。

首次打开时填写：

- `设备名称`，用于远程页切换和区分设备；
- `巴法云主题`，通常以 `005` 结尾；
- `巴法云 Private Key`。

远程页最多保存 8 台设备，可通过右上角“设备配置”新增、删除、切换设备并编辑巴法云参数；当前选中的设备会保存在浏览器中，下次打开仍默认使用该设备。每台设备分别保存名称、Private Key 和主题。旧版单设备配置会在首次打开新版页面时自动迁移为“LazyStick 1”。字段名称与 LazyStick 设置页保持一致。

配置保存在 `lazystick.icu` 在当前浏览器中的 `localStorage`，关闭页面或浏览器后仍会保留；清除该网站的数据、使用无痕模式或更换浏览器/设备后不会保留。旧域名保存的数据不会自动迁移到新域名。配置不会写入 LazyStick，也不会发送给巴法云以外的服务。不要在公共或共享设备上保存私钥；可以随时删除单台设备的本地配置。

## 工作方式

页面调用巴法云官方 HTTPS 消息接口 `https://apis.bemfa.com/va/postJsonMsg`，以 `type=1` 向 MQTT 主题发布 LazyStick 指令。这样不会使用与 LazyStick 相同的 MQTT Client ID，也不会导致设备的 MQTT 长连接被重复登录挤下线。

页面右上角以简洁状态标签显示当前设备状态，并每 30 秒通过巴法云官方接口自动更新。显示“在线”表示配置的 MQTT 主题至少存在一个在线订阅；显示“离线”表示巴法云没有检测到在线订阅。它可以反映 LazyStick 的 MQTT 连接状态，但无法证明电脑已经执行了上一条指令。若多个设备订阅同一主题，在线状态代表这些订阅中的整体状态，无法区分具体设备。

电脑操作发送单条指令；媒体、宏和台灯操作依次发送模式与风速两条指令，间隔 350 ms，满足 LazyStick 的 10 秒组合窗口：

| 页面操作 | 发布消息 |
|---|---|
| 电脑开机 / 唤醒 | `on#1` |
| 电脑休眠 | `on#2` |
| 电脑关机 | `on#3` |
| 台灯开灯、关灯、阅读、放松、侧灯（屏阅） | `on#4`，再发送风速 `0～4` |
| 静音、音量 +、音量 -、下一首、上一首、播放 / 暂停 | `on#6`，再发送风速 `0～5` |
| 宏 1～宏 6 | `on#7`，再发送风速 `0～5` |

“发送成功”只表示巴法云接受了消息，不代表 LazyStick 在线或电脑、台灯已经执行完成。
远程页面已删除“进入设置模式”，该按钮仅保留在设备本地网页。
台灯控制需先升级支持华为台灯的固件，再在设备设置页导入电脑工具导出的授权文件并启用。
旧固件收到 `on#4` 仍会进入设置，不能使用新台灯按钮。华为授权文件和账号凭据不保存在远程网页。

## 浏览器要求

页面需要联网并支持 `fetch`、`localStorage`、`AbortController` 和现代 JavaScript 语法的浏览器。如果浏览器或安全软件禁止本地文件访问网络，请使用另一款现代浏览器打开，或将整个文件夹部署到任意静态 HTTPS 网站。

## 独立华为授权工具

入口：<https://lazystick.icu/huawei-auth/>，主页不展示入口按钮。
Windows 用户下载并运行本机助手后，在网页登录华为账号、完成验证码验证、选择台灯，
即可下载供 LazyStick 导入的 JSON。助手直连华为，站点不接收账号密码或授权；
页面不读取远程控制配置。使用方法、源码构建和数据说明见 [工具说明](huawei-auth/README.md)。

## 上传发布

在仓库根目录执行：

```powershell
.\scripts\upload.ps1 -Message "更新远程控制页面"
```

也可以运行 `scripts\upload.cmd`。脚本会检查仓库状态，提交当前仓库的改动并推送到 `origin` 的当前分支；GitHub Pages 随后会自动更新。可用 `-Remote`、`-Branch` 指定其他远端或分支，用 `-WhatIf` 仅查看计划操作。
